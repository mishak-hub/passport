Live word ranking · Jev

When Passport is enabled, send the current word, up to 600 characters of its sentence, and up to ten dictionary candidates to TypeSafe to improve their order. This is cloud processing even when sentences use local Ollama. Password and other excluded fields are not processed. TypeSafe account usage and limits apply.

Local suggestions appear immediately. Jev considers up to ten candidates and displays the best five, ranking loanwords and native-origin words by meaning, context and everyday usage. After 220 ms without typing, Jev can reorder them. Space adopts the current candidate without waiting; late results cannot replace it. A 2.5-second timeout, short-lived memory cache and 40-request-per-minute limit keep local suggestions usable.

Sentence model

Only sentence reconstruction calls the API. Your key stays in this browser’s extension storage. Google’s quotas and data-use terms apply.

Get an API key ↗

Install and run Ollama, then download a multilingual instruction model that fits your computer. Passport lists models already installed; it does not download models or switch to the cloud.

Local setup

Start Ollama, install a model using its app, then click Refresh models. To ensure Ollama itself never uses cloud models, set OLLAMA_NO_CLOUD=1 and restart it. If its origin check blocks the extension, add this extension’s origin to OLLAMA_ORIGINS and restart Ollama. Keep the endpoint on localhost.

Instant words

English, Spanish, French, Japanese and Mandarin dictionaries are included. Local suggestions need no account or API. Optional live Jev ranking sends words and sentence context to TypeSafe only when enabled above.

Candidates appear while you type. Tab cycles; Space adopts the current candidate immediately, including provisional articles and particles; sentence reconstruction fixes grammar later. Unknown words stay as typed. Grammar templates, affix-only senses and malformed suggestions are filtered out. Approximate spellings are suggestions, not guaranteed corrections. Non-English pairs may use an English bridge, so check ambiguous meanings. Pronunciations are shown where the dictionary provides them.

After half a second, the selected model can suggest a complete sentence. Without a trailing boundary, Space accepts the preview; ordinary typing continues the draft. Ending punctuation requests reconstruction immediately. Enter always sends/searches the visible text. Model response time is additional to the pause.

Use Undo to recover earlier wording. Click translated words to see meanings and hear installed local voices. Detailed character explanations come with sentence results, without additional word-level model calls.

Try Passport

  1. Type hello. Suggestions come from the local dictionary. Tab cycles through choices; Space adopts one. Optional Jev ranking can improve their order.
  2. Type My friend drinks coffee without punctuation. Pause for half a second. When a sentence preview arrives, Space accepts it; typing another letter dismisses it.
  3. Try the sentence again with an ending period, question mark or exclamation mark. Reconstruction starts immediately. Enter always belongs to the field.
  4. Click a translated word for its definition and pronunciation. The speaker uses an installed local voice. Use the companion’s Undo arrow to recover earlier wording. Changed explicit choices require the checkmark.
